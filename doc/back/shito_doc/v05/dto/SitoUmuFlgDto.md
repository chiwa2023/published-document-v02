# SitoUmuFlgDto

## 概要

政党交付金使途報告書V5の各要素が存在するかどうか、有無を表した文字列表示項目

## サンプルXML

```xml
<SitoUmuFlgDto>
  <SITO_UMU>111100000000001100</SITO_UMU>
</SitoUmuFlgDto>
```

## プロパティと詳細

|  プロパティ名   | XMLタグ名  | データ型 |                                  説明                                   |
| --------------- | ---------- | -------- | ----------------------------------------------------------------------- |
| `umuStatusText` | `SITO_UMU` | `String` | データ存在の有無一覧テキスト。項目あり:`1`、項目なし:`0`。例:`11001010` |
