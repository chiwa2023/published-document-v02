# Sheet0802Dto

## 概要

政党交付金使途報告書V5の様式8の2（資産等の内訳）の全体データDto。

## XML要素

ルート要素名は `SYUUSHI08_2` となります。( `AllSheet` クラスで定義)

## プロパティ

|  プロパティ名  | XMLタグ名 |    データ型    |           説明            |
| -------------- | --------- | -------------- | ------------------------- |
| `kbn080201Dto` | `KUBUN1`  | `Kbn080201Dto` | 様式8の2の1：資産等の内訳 |
| `kbn080202Dto` | `KUBUN2`  | `Kbn080202Dto` | 様式8の2の2：借入金の内訳 |

## `Kbn080201Dto` (`KUBUN1`) の詳細

`KUBUN1`（資産等の内訳）のデータDtoです。

| プロパティ名 | XMLタグ名 |        データ型         |       説明       |
| ------------ | --------- | ----------------------- | ---------------- |
| `list`       | `ROW`     | `List<RowShito0802Dto>` | 資産の項目リスト |

## `Kbn080202Dto` (`KUBUN2`) の詳細

`KUBUN2`（借入金の内訳）のデータDtoです。

| プロパティ名  |  XMLタグ名   |        データ型         |        説明        |
| ------------- | ------------ | ----------------------- | ------------------ |
| `totalAmount` | `KINGAKU_GK` | `Long`                  | 借入金の合計金額   |
| `list`        | `ROW`        | `List<RowShito0802Dto>` | 借入金の項目リスト |

## `RowShito0802Dto` (`ROW`) の詳細

`KUBUN1` および `KUBUN2` 内の `list` に含まれる `ROW` タグの各項目は、以下の構造を持つ `RowShito0802Dto` で表現されます。

| プロパティ名  |  XMLタグ名   | データ型  |   説明   |    値の制限    |
| ------------- | ------------ | --------- | -------- | -------------- |
| `rowNo`       | `ICHIREN_NO` | `Integer` | 連番     | 未調査／未実装 |
| `itemName`    | `KOUMOKU_NM` | `String`  | 項目名称 | 未調査／未実装 |
| `accrualDate` | `DT`         | `String`  | 発生日   | 未調査／未実装 |
| `amount`      | `KINGAKU`    | `Long`    | 金額     | 未調査／未実装 |
